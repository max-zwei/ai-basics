# README

## context
The repository consist of homework and assessments to pass the level expectations of SE_14 Artifical Intelligence Basics at CODE University of Applied Sciences. 
These **level expectations** are:
Students who want to pass this module should demonstrate a basic level of knowledge in the field of AI and its branches Planning, Optimization, Reasoning, and Machine Learning. They should also possess a specific level of knowledge in one of them and have reflected on how they solved AI problems. “Basic Level” means that students know how to formulate a problem such that standard algorithms in the respective branch can be applied and know some of the options available to solve it. “Specific Level” means that students are familiar with specific algorithms of the respective branch and can select, tune, and evaluate an appropriate algorithm to achieve reasonable results for a problem within this area.

## structure
Each folder consists of a README with the task description and supporting material. 

## instructions
To run a project follow the specific instructions per task as stated in its README.
